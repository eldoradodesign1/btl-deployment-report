# Révision BTL - Deployment report

## Login

La fenêtre conserve uniquement la marque, le titre **Choisissez votre avatar**, les deux cartes **Vodacom** et **BTL**, puis le bouton d’ouverture correspondant. Elle ne présente plus de description opérationnelle, de mot de passe, d’adresse e-mail ou de phrase sur les détails de performance.

## Vodacom

Vodacom retrouve les menus **Dashboard**, **Activité**, **Agents**, **Shops**, **Activations**, **Analyse croisée**, **Qualité des données**, **Import & sources** et **Paramètres**. Les vues terrain et lecture sont en mode lecture seule. L’import est accessible afin de mettre à jour la source, mais les champs de renommage et de configuration restent réservés à BTL.

## Notifications

La cloche ouvre un centre local qui regroupe les changements de source, les alertes qualité et les confirmations d’import. Les notifications restent dans le navigateur et sont marquées comme lues après ouverture.
